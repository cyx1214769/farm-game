# 英雄小镇（FarmGame）

一个**微信小游戏**：在爷爷留下的荒废农场上种菜、养动物、卖钱，把农场一点点做大。

- **引擎**：Cocos Creator 3.8.8 + TypeScript
- **画面**：2D 等距（约 30° 俯角），轻卡通风格
- **平台**：先微信小游戏，之后考虑抖音小游戏

## 玩法

- **种菜**：10 种作物，分短周期（几秒~几分钟）、中周期、长周期三档
- **牧场**：鸡 / 羊 / 牛，买来是幼崽 → 长大 → 喂食产出（蛋/毛/奶）或者卖掉换肉
- **变现**：市场按市价卖，订单按 1.5 倍收（订单会指定作物）
- **扩张**：开垦田地、买动物、扩建围栏上限
- **离线生长**：关掉游戏，作物和动物也在长（靠时间戳结算）

## 目录结构

```
FarmGame/
├── assets/
│   ├── scripts/          游戏代码（15 个脚本）
│   └── resources/art/    贴图（运行时加载）
├── settings/             引擎模块裁剪、构建配置
└── build/                构建产物（不进版本库）
```

根目录的几个 `.md` 是设计与开发文档（路线图、美术规格、地图方案等）。

## 开发流程

1. Cocos 里改代码 → `Ctrl + S` → 项目 → 构建发布 → 构建
2. 跑一次 `修复微信配置.bat`（把 AppID 写对，否则微信工具报错）
3. 微信开发者工具导入 `FarmGame/build/wechatgame-XXX`

## 备份

- `备份代码.bat`：本地打快照（存到 `backup/日期_时间/`）
- git 提交历史：每改完一件事提交一次
