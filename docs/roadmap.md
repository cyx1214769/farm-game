# 从零开发《溪畔农场》路线图

## 立刻开始：第一周任务清单

### 任务 1 · 注册账号（今天，1-2 小时）

**目的不是注册成功，是"体检"**——看看你能不能注册、需要交什么材料、会不会卡住。

#### 先分清两种账号

| | 测试号 | 正式账号 |
|---|---|---|
| 怎么拿 | 公众平台申请，秒给 | 注册 + 审核 |
| 能开发调试 | 能 | 能 |
| 能上传提审 | **不能** | 能 |
| 能发布上线 | **不能** | 能 |
| 需要什么 | 一个微信号 | 邮箱 + 主体信息 + 备案 |
| 广告变现 | 不能 | 能 |

开发阶段用测试号完全够用。但**发布必须靠正式账号**，所以尽早办。

#### 注册正式账号的步骤

1. 打开 `mp.weixin.qq.com`，点右上角「立即注册」
2. 选择「**小程序**」（不是订阅号、不是服务号）
3. 填一个**没注册过公众平台的邮箱**，设置密码，收邮件激活
4. 选择主体类型：
   - **个人**：填身份证信息，本人微信扫码验证
   - **企业**：填营业执照信息
5. 填小程序名称（一年只能改 2 次，想好再定）
6. 提交后进入后台
7. 后台「设置 → 基本设置」完善信息，添加**服务类目**
8. 完成小程序备案（后台会有入口，个人可以办）

**注意**：游戏类目的资质要求各平台调整过多次，以注册流程里实际显示的要求为准。如果个人主体加不了游戏类目，就要考虑升级企业主体——这件事越早发现越好。

- 微信：`mp.weixin.qq.com` → 注册 → 选择「小程序」→ 到后台添加「游戏」服务类目
- 抖音：`open.douyin.com` → 找到小游戏入口注册
- 记录三件事：卡在哪一步、要交什么材料、大概要等多久
- 如果个人主体注册不下来，**现在就知道**，后面的计划要跟着改

### 任务 2 · 装工具（半天）

- **Cocos Dashboard + Cocos Creator 3.8.x**（cocos.com 下载，免费）
- **微信开发者工具**（微信公众平台官方下载页）
- 两个工具都用微信扫码登录

### 任务 3 · 跑通链路（1-2 天）★最关键

1. Cocos 新建空项目
2. 场景里拖一个 Label 节点，文字改成「你好」
3. 构建发布 → 选择「微信小游戏」
4. 打开微信开发者工具，导入第 3 步的构建产物
5. 点「预览」，用手机扫码
6. 手机上出现「你好」

**完成标准：手机屏幕上出现「你好」两个字。**

这一步不产出任何玩法，但它是新手最大的坎。跑通了，后面就是正常开发了。

### 并行任务 · 办备案

备案要走几天到几周，和学 Cocos 同时进行，不要等游戏做完才办。

### 这一周不要做的事

- 不要买美术素材（玩法没跑通之前，你不知道自己需要什么规格的图）
- 不要买游戏源码或模板
- 不要把教程全部看完再动手
- 不要碰养动物、养鱼、装饰

## 0. 先搞清楚四件事

### 0.1 你要注册的是「小游戏」，不是「小程序」

微信和抖音都把「游戏」单独划成了一个类目，叫**小游戏**。普通小程序不允许提供游戏服务，审核会直接拒。这两个是不同的注册入口、不同的技术栈、不同的审核规则。

对你的农场游戏来说，必须走小游戏。理由：小游戏用 Canvas 渲染，能自由画场景、做动画、跑地图；普通小程序用 WXML/WXSS 排版，做游戏画面会非常别扭。

### 0.2 主体资格决定你能怎么赚钱

| 主体 | 能否内购（虚拟支付） | 能否接广告 |
|---|---|---|
| 个人 | 不能 | 能，但要先开通「流量主」，有累计访客门槛 |
| 企业 | 能 | 能 |

新手建议：先注册个人主体，只做广告变现。等验证了玩法、有了数据，再考虑升级企业主体做内购。个人主体注册免费，用身份证即可。

注意：微信小游戏的流量主开通有累计独立访客（UV）门槛；抖音的口径不同。具体数值经常调整，以官方最新公告为准。

### 0.3 备案

国内的小程序 / 小游戏上架前必须完成 ICP 备案。个人可以备案，需要准备身份证信息，走微信或抖音提供的备案入口。这一步走流程要几天到几周，**尽早办，不要等游戏做完了才办**。

### 0.4 包体限制

小游戏有严格的首包大小限制（微信和抖音都在几 MB 量级，超了无法启动或审核不过）。这意味着**你的美术资源不能全打进包里**，大图要放远端 CDN，进游戏后按需下载。这个限制会直接影响你的美术方案，必须在开工前就知道。

具体数值请查官方最新文档，各平台历史上调整过多次。

## 1. 技术选型

**推荐：Cocos Creator（3.8 或更高版本）。**

理由：

- 中文文档和社区最全，中文教程最多，遇到问题搜得到
- 有场景编辑器，大部分工作是在界面上拖拽，不是敲代码
- 内置微信小游戏的构建目标，抖音小游戏有对应的构建目标 / 插件
- 免费
- 脚本用 TypeScript，比原生 Canvas API 简单得多

其他选项：

- **LayaAir**：国产，也支持多平台，但社区比 Cocos 小
- **Unity**：导出小游戏包体偏大，不太适合，不建议
- **原生 Canvas API 直接写**：不推荐给新手，等于所有轮子自己造

## 2. 开发步骤

### 阶段 0 · 跑通链路（1-2 周）★最关键

**目标：在手机上打开一个自己做的、只有一句话的页面。**

这一步不产出任何玩法，但它比写游戏逻辑重要得多——新手 90% 卡在这里。跨过去，后面就顺了。

1. 注册微信小游戏账号，拿到 AppID
2. 下载安装「微信开发者工具」
3. 下载安装 Cocos Creator
4. 新建空项目 → 放一个 Label 显示「你好」
5. 构建发布 → 微信小游戏
6. 用微信开发者工具打开构建产物 → 点「真机预览」→ 手机上扫码看到「你好」

### 阶段 1 · 最小可玩（2-4 周）

**目标：一块地，种一颗萝卜，等它成熟，点了收获，数字增加。**

要学：节点、组件、预制体、TypeScript 脚本、按钮点击事件、定时器。

产出一个能玩 30 秒的东西就够了，不要贪多。

### 阶段 2 · 核心循环（4-8 周）

- 作物配置表（用 JSON 存，不要写死在代码里）
- 多种作物、多个地块
- 时间系统：真实时间流逝 + 离线结算（关掉游戏也在长）
- 存档：`wx.setStorageSync` 本地存
- 商店、仓库、卖菜

### 阶段 3 · 成长与留存（4-8 周）

- 订单系统
- 市场波动
- 建筑修复（阶段 0/1 的地块解锁）
- 等级与经验

### 阶段 4 · 变现（2-4 周）

- 接入激励视频广告
- 离线收益翻倍、加速成熟、双倍收获
- 广告冷却与频次控制

### 阶段 5 · 上线与移植（2-4 周）

- 提审、备案、发布微信版
- 做抖音适配，导出抖音包，提审

**总时间预估：业余时间投入，6-12 个月。**

## 3. 素材从哪来

### 3.1 你需要哪些素材

| 类别 | 内容 | 数量级 |
|---|---|---|
| 地块 | 草地、泥土、水面、石板 | 4-8 张 |
| 作物 | 每种作物 4-5 个生长阶段 | 20 种 × 5 = 100 张 |
| 建筑 | 房子、鸡舍、谷仓、加工坊、温室、风车 | 10-15 个 |
| 动物 | 鸡、牛、羊、鱼、鸭，各 4 个方向 | 20-40 张 |
| 装饰 | 栅栏、路灯、花坛、稻草人、摆件 | 50-100 个 |
| UI | 按钮、面板、图标、货币图标 | 30-50 个 |
| 特效 | 收获、升级、金币飘字 | 5-10 个 |
| 音效 | 点击、播种、收获、金币、升级 | 10-20 个 |
| 音乐 | 白天、夜晚各 1 首 | 2 首 |

### 3.2 推荐的来源

**免费可商用（最安全）：**

- **Kenney.nl** — CC0 授权，完全免费商用，有大量 2D 农场 / 经营素材包，质量统一。新手首选。
- **itch.io** — 搜 `farm asset pack`，免费和付费都有，每个包的授权单独看。

**注意授权（可用于原型）：**

- **OpenGameArt.org** — 授权混合，每个资源都要单独确认
- **Game-icons.net** — 图标，CC BY，需要署名
- **freesound.org** — 音效，授权混合，商用要挑 CC0

**付费采购 / 定制：**

- 淘宝、闲鱼上的素材包店（几十到几百元一套）
- 站酷、B站上找画师定制（一套完整农场素材，1-3 万）
- 买现成的小游戏源码改（要确认版权来源，很多是盗版）

### 3.3 素材最大的坑：风格不统一

从五个不同地方各买一套素材，拼在一起会立刻露馅——光照明暗不同、线条粗细不同、透视角度不同。

**所以：要么整套买同一个作者的，要么整套定制。不要东拼西凑。**

### 3.4 字体

中文小游戏**不要自己打包中文字体**，一个中文字体动辄几 MB 到几十 MB，会直接把包体撑爆。用系统默认字体。

## 4. 微信 → 抖音的移植

这是你问的关键点。两个平台的 API 长得像但名字不同：

| 功能 | 微信 | 抖音 |
|---|---|---|
| 登录 | `wx.login` | `tt.login` |
| 存储 | `wx.setStorageSync` | `tt.setStorageSync` |
| 激励视频 | `wx.createRewardedVideoAd` | `tt.createRewardedVideoAd` |
| 分享 | `wx.shareAppMessage` | `tt.shareAppMessage` |

**最关键的一条建议：从第一天就写一层平台适配层。**

不要在代码里到处直接写 `wx.xxx`。而是自己包一个 `Platform` 模块，游戏逻辑只调用 `Platform.login()`、`Platform.showRewardAd()`。这样移植抖音的时候，你只需要改这一个文件，而不是满项目找几十处。

这是新手最容易忽略、后期最痛的一件事。

## 5. 新手最容易卡住的五个点

1. **想一次做完整个游戏。** 结果三个月后什么都有一点点，什么都玩不了。永远先做能跑起来的最小版本。
2. **把美术资源全打进包里。** 构建直接失败。资源要放远端 CDN。
3. **到处直接写平台 API。** 移植抖音时改到崩溃。
4. **数值写死在代码里。** 想调一次平衡要改代码重新构建。全部放 JSON 配置表。
5. **跳过备案就开始做。** 做完了发现上不了架，白等几周。

## 6. 现实一点的预期

这个游戏的规模（种菜 + 养动物 + 养鱼 + 订单 + 市场 + 装饰 + 图鉴 + 评级 + 广告）是一个**中型项目**。全功能做完，一个人业余时间大概需要一年。

所以第一版的范围一定要砍到：**种菜 + 卖菜 + 升级 + 订单**。先把这一条链路完整跑通、上线、看到真实数据，再决定要不要加养动物。

## 7. 包体管理：什么时候要分包

### 三层结构

```
主包（首包）      ≤ 4MB        启动时必须下载
分包 A / B / C…  总包上限更大   需要时才下载
远端 CDN          无硬上限      按需拉取
```

### 主包放什么

**"玩家前 3 分钟会用到的一切"**

- Cocos 引擎（裁剪后约 1.35 MB）—— 这部分是固定开销，跑不掉
- 你的游戏代码（很小，几十 KB）
- 开局场景：地块、路、房子、树、井、风车
- 前几种作物（萝卜、白菜、番茄）
- 基础 UI

合计大约 1.9 MB，给主包留 2 MB 以上余量。

### 分包怎么切

**按「玩法」切，不要按「资源类型」切。**

| 分包 | 装什么 | 什么时候下载 |
|---|---|---|
| 农场 | 后期作物的图 | 解锁这些作物时 |
| 牧场 | 动物 + 牧场建筑 | 解锁养动物时 |
| 水塘 | 鱼 + 钓鱼界面 | 解锁钓鱼时 |
| 加工坊 | 配方 + 加工品 | 解锁加工时 |
| 装饰 | 几百个小物件（最大的一块） | 进装饰界面时 |
| 活动 | 节日限定素材 | 活动开始时 |

按玩法切的好处：玩家解锁某个玩法时，正好需要那一整套东西，下载时机天然吻合。

如果按类型切（图片包 + 音效包 + 动画包），玩任何一个玩法都得下载好几包，反而更慢。

### CDN 放什么

- 节日活动素材（一年只用一次）
- 海量装饰（玩家不会全用）

上 CDN 需要：一个 ICP 备案的域名 + 对象存储（阿里云 OSS / 腾讯云 COS，一年几十到几百块）。

### 什么时候动手

**当包体超过 3 MB 时开始分包**，留 1 MB 缓冲。

按开发节奏，大概是在**开始做装饰系统**的时候。

### 分包要改什么（到时候的活儿）

1. 把资源按玩法分到不同文件夹
2. 在 Cocos 里把这些文件夹「配置为 Bundle」
3. 代码里用 `assetManager.loadBundle('牧场')` 按需加载
4. 构建配置里确认分包设置

**注意：加载是异步的**，所以进玩法界面时要处理「正在下载」的过程——这一点在切分包的时候要专门做。
