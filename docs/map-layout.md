# 农场地图布局方案

参考方向：《我的花园世界》那种——**竖屏 + 方形地图 + 轻微拖动 + 点建筑进入内部**。

目标不是把画面塞满，而是"有留白但不空"。

---

## 一、地图规格

```
设计分辨率   720 × 1280（竖屏）
地图尺寸     880 × 1520
拖动范围     横向 ±80，纵向 ±120
可见比例     一屏能看到地图约 70%
```

**为什么不做成 2-3 屏的大地图：** 地图一大，要填的内容就成倍增加，而且玩家会"迷路"。**只比屏幕大一点点**，能感觉到"外面还有东西"就够了。

坐标系统：地图中心是 (0, 0)，y 向上为正。

---

## 二、整体布局

```
        x = -440 ────────── 0 ────────── +440
                  ┌───────────────────────┐  y = +760
                  │                       │
                  │   🌳        🌳        │
                  │       🏠 房子          │  家
                  │          ⛲ 水井       │
   y = +240       │                       │
                  │  ┌───────────────┐    │
                  │  │               │    │
                  │  │   田  地       │ 🏭 │  种植区
                  │  │               │加工坊│
   y = -240       │  └───────────────┘    │
                  │          💧 水塘       │
                  │  🐑 牧场              │  养殖区
                  │             🌳        │
                  └───────────────────────┘  y = -760
```

**视觉重心在中间那块田地**——它是整个画面最大的一块，玩家一眼就知道"这是种菜的地方"。其它东西围在四周。

## 三、各区域放什么

### 家（上方）

| 物件 | 大概位置 | 说明 |
|---|---|---|
| 房子（主屋） | (-240, 480) | 点击进入「农场信息 / 装饰」 |
| 水井 | (-40, 540) | 装饰，以后可以做"浇水加速" |
| 树 ×3 | (-420, 560) (120, 600) (330, 530) | 纯风景 |
| 小路 | 从房子通向田地 | **最重要的一条**，见下 |

### 种植区（中间，主体）

| 物件 | 说明 |
|---|---|
| 田地 | 3×5 = 15 块，占画面最大面积 |
| 小路 | 绕着田地一圈，把田地和其它区域连起来 |
| 花圃 | 田地边缘点缀 |

### 加工区（右侧）

| 物件 | 大概位置 | 说明 |
|---|---|---|
| 加工坊 | (300, -40) | 点击进入「加工」界面 |
| 仓库 | (400, 100) | 以后可能做独立界面 |

### 养殖区（下方）

| 物件 | 大概位置 | 说明 |
|---|---|---|
| 牧场 | (-250, -420) | 点击进入「牧场」界面 |
| 水塘 | (230, -430) | 点击进入「钓鱼」界面 |
| 树 ×2 | (-430, -300) (420, -250) | 纯风景 |

## 四、建筑清单（点击行为 + 状态显示）

**这张表是整个方案的核心。**

| 建筑 | 点击后 | 显示什么状态 |
|---|---|---|
| **田地** | **直接操作，不进入** | 成熟作物带金边（已有） |
| 牧场 | 进入「牧场」全屏界面 | 有蛋/奶可收时，屋顶冒图标 |
| 水塘 | 进入「钓鱼」界面 | 有鱼可钓时，水面冒水花 |
| 加工坊 | 进入「加工」界面 | 生产中有烟；做完了打勾 |
| 仓库 | 进入「仓库」界面 | 快满时提示 |
| 房子 | 打开「装饰 / 农场信息」面板 | 有新装饰可用时冒光点 |

### 两条规则

**规则一：田地绝对不做"进入"。** 种菜是最高频的操作，必须点一下就种、点一下就收。任何"进去再出来"都会毁掉手感。

**规则二：每个建筑都要能"自己说话"。** 玩家在农场上一眼扫过去，就知道哪个有事要做、哪个没事。不然他得一个个点进去看，很快就烦了。

## 五、UI 层（浮在场景上面的）

```
┌────────────────────────────────┐
│ 金币 1.2万  仓库 12     [菜单]  │  ← 顶部：资源 + 菜单
│                     [胶囊按钮]  │
│                                │
│    📋 订单 (2)                 │  ← 左侧：订单入口（带可交数量）
│                                │
│         （游戏画面）            │
│                                │
│                                │
│         [种子栏]               │  ← 底部：种子（可收起，已有）
└────────────────────────────────┘
```

| 位置 | 放什么 | 为什么 |
|---|---|---|
| 顶部左 | 金币、仓库 | 资源，随时要看 |
| 顶部右 | 菜单（设置、公告） | 低频，收起 |
| 左侧中 | **订单条**（显示可交几单） | 订单是目标引擎，要一直看得见 |
| 底部 | 种子栏（可收起，已有） | 高频操作 |

**市场不放顶部了。** 建议做成场景里的一个**摊位**（在房子和加工坊之间），点它开面板。因为市场是有实体的地方，做成建筑更有代入感，而且能显示"今天价格波动"的状态。

## 六、拖动规则

| 项 | 规则 |
|---|---|
| 手势 | 单指拖动移动地图 |
| 和点击的区分 | 手指移动超过 **10px** 才算拖动，否则算点击 |
| 边界 | 地图边缘不能被拖进屏幕内（不能看到地图外的空白） |
| 惯性 | 先不做。松手就停，手感更可控 |
| 弹回 | 如果玩家拖出界，平滑弹回边界 |

**顺序很重要：先填内容，再开拖动。** 反过来的话，你会拖动一个空荡荡的地图，感觉更差。

---

## 七、解锁顺序

按等级解锁"新玩法"，用钱解锁"数值扩张"（沿用之前定的原则）。

| 阶段 | 解锁什么 | 条件 |
|---|---|---|
| 开局 | 田地（5 格免费）+ 房子 | — |
| 第 1 天 | **牧场**（养鸡） | Lv.3 |
| 第 2-3 天 | **水塘**（钓鱼） | Lv.5 |
| 第 4-6 天 | **加工坊** | Lv.8 |
| 第 1-2 周 | 温室、装饰系统 | Lv.12 |
| 之后 | 仓库、镇上 | Lv.15+ |

**新解锁的建筑要有一次引导**（手指指过去 + 一句话），不然玩家找不到。

---

## 八、现在有什么 / 以后加什么

| 区域 | 现在 | 以后加 |
|---|---|---|
| 家 | 房子、水井、树 ✓ | 晾衣绳、花圃、宠物 |
| 种植区 | 田地、小路 | 花圃、稻草人 |
| 加工区 | 加工坊（占位） | 仓库、烟囱冒烟 |
| 养殖区 | 牧场、水塘、树 ✓ | 更多动物、小船、码头 |
| 边缘 | — | 篱笆围一圈、远处的山、云 |

**加东西的优先级：小路 > 花圃 > 篱笆 > 其它。**

小路的性价比最高——**一条路就能把散落的建筑连成"一个农场"**，这是从"几块色块"到"一个地方"最快的一步。

---

## 九、施工顺序（建议）

| 步 | 做什么 | 需要美术吗 |
|---|---|---|
| 1 | 加 World 容器（为拖动做准备） | 不用 |
| 2 | 按这个方案重排建筑位置 | 不用 |
| 3 | 加小路 + 花圃 + 篱笆（色块） | 不用 |
| 4 | 加纵向拖动 | 不用 |
| 5 | 建筑状态显示（蛋、烟、勾） | 不用 |
| 6 | 换真实美术 | **要** |

**前五步做完，你的农场就是"一个地方"了**，而且你手里会有一张准确的施工图，买美术时可以直接给画师看。
